# Flutter 3.47 (12 Aug 2026)

Index: https://docs.flutter.dev/release/breaking-changes (section "Released in Flutter 3.47")
Release post: https://flutter.dev/blog/whats-new-in-flutter-3-47

## Standalone Material & Cupertino (opt-in now, deprecation of the SDK libraries planned for the Nov 2026 stable)

`package:flutter/material.dart` → `package:material_ui/material_ui.dart`,
`package:flutter/cupertino.dart` → `package:cupertino_ui/cupertino_ui.dart`.
Migration: `flutter pub add material_ui cupertino_ui` + `dart fix --apply --code=migrate_design_widgets`,
`localizationsDelegates: GlobalMaterialLocalizations.delegates`, `MaterialUiCompatibilityBridge`
for unmigrated dependencies. Full details: the **flutter-material-ui** skill. Not required for
the upgrade itself — offer it, do it when asked.

## Android: enable built-in Kotlin

3.47 supports `android.builtInKotlin=true` in `android/gradle.properties`. Requires AGP 9+,
the app migrated (see 3.44.md: remove `kotlin-android` + `kotlinOptions`, add
`kotlin { compilerOptions { jvmTarget = JvmTarget.JVM_17 } }`) **and all plugins migrated**.

```properties
android.newDsl=false          # keep until Flutter finishes the new-DSL migration
android.builtInKotlin=true    # only once app + every plugin no longer applies KGP
```

If any plugin still applies KGP, keep `android.builtInKotlin=false` and report it to the author.
Verify with `flutter build apk`.

## `describeEnum` removed (not covered by `dart fix`)

```diff
-describeEnum(Priority.high)
+Priority.high.name
```

Drop the now-unused `package:flutter/foundation.dart` import if nothing else needs it.

## Platform minimums and tooling

- **iOS minimum 15** (was 13), **macOS minimum 12** (was 10.15): bump
  `IPHONEOS_DEPLOYMENT_TARGET` / `platform :ios, '15.0'` in the Podfile and the
  `MinimumOSVersion`; same for macOS.
- **UIScene required with Xcode 27 / iOS 27 SDK** — see 3.38.md (custom AppDelegates need the
  manual migration or the app crashes at launch).
- **Intel Macs:** the CLI warns on Intel builds; will become an error later.
- **Wasm:** `dart:html` is unsupported under Wasm → use `package:web` + `dart:js_interop`.
- **Impeller is the default on macOS, Windows and Linux**; opt-out fallbacks will be removed.

## Rendering / semantics

- **OpenGL ES render-to-texture is stored top-down**: fragment shaders that conditionally
  flipped texture coordinates on OpenGL ES must drop the flip.
- **Semantics `header` / `headingLevel`** behaviour updated on iOS and Android — re-check
  accessibility tests that assert heading semantics.
