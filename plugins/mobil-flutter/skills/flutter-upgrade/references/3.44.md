# Flutter 3.44 (May 2026)

Index: https://docs.flutter.dev/release/breaking-changes (section "Released in Flutter 3.44")

## Android: AGP 9 and built-in Kotlin

Source: https://docs.flutter.dev/release/breaking-changes/migrate-to-built-in-kotlin

AGP 9 makes **built-in Kotlin** the default; apps/plugins that apply the Kotlin Gradle Plugin
(`kotlin-android` / `org.jetbrains.kotlin.android`, "KGP") **fail to build**. AGP 9 also only
uses the new DSL interfaces.

Flutter 3.44 added **temporary** support so projects build while migrating: the Flutter tool
adds these to `android/gradle.properties` on the next `flutter run` / `flutter build apk`
(add-to-app host apps must add them by hand):

```properties
android.newDsl=false
android.builtInKotlin=false
```

Enabling built-in Kotlin (`android.builtInKotlin=true`) needs **Flutter 3.47+** (see 3.47.md).
Support for applying KGP will be removed in a future Flutter version → migrate now.

Only migrate if the app currently applies KGP. Apps without KGP only need `android.newDsl=false`.

### App migration (`android/app/build.gradle.kts`)

```diff
 plugins {
     id("com.android.application")
-    id("kotlin-android")
     id("dev.flutter.flutter-gradle-plugin")
 }

 android {
     // ...
-    kotlinOptions {
-        jvmTarget = JavaVersion.VERSION_17.toString()
-    }
 }

+kotlin {
+    compilerOptions {
+        jvmTarget = org.jetbrains.kotlin.gradle.dsl.JvmTarget.JVM_17
+    }
+}
```

Groovy (`build.gradle`): remove `apply plugin: 'kotlin-android'` and `kotlinOptions`, add the
same `kotlin { compilerOptions { jvmTarget = ... } }` block. Add-to-app hosts: remove
`alias(libs.plugins.kotlin.android)`. The `org.jetbrains.kotlin.android` entry in
`settings.gradle(.kts)` can go once nothing applies it.

### Plugins

Every Flutter plugin the app uses must also have migrated before built-in Kotlin can be
enabled. Check each plugin's changelog / `android/build.gradle` for `kotlin-android`; upgrade
(`flutter pub upgrade --major-versions`) or report it to the author with a link to
https://docs.flutter.dev/release/breaking-changes/migrate-to-built-in-kotlin/for-plugin-authors.
Until then keep `android.builtInKotlin=false`.

Never "fix" this by downgrading AGP below 9 or merely bumping the Kotlin plugin version.

## `IconData` is now `final`

`enum X implements IconData` / `class X extends IconData` → compile error
`The class 'IconData' is 'final' and can't be extended or implemented outside of its library.`
(Part of asset tree-shaking; `IconData` params are `@mustBeConst`.)

```dart
// Simplest: static consts
abstract final class AppIcons {
  static const IconData add = IconData(0xe047, fontFamily: 'MaterialIcons');
  static const IconData done = IconData(0xe876, fontFamily: 'MaterialIcons');
}
// Icon(AppIcons.done) keeps working; make it `const Icon(AppIcons.done)`.

// If you need .values / a distinct type: wrapper class
final class AppIconData {
  const AppIconData._(this.iconData);
  final IconData iconData;
  static const add = AppIconData._(IconData(0xe047, fontFamily: 'MaterialIcons'));
  static const values = [add];
}
```

Non-const `IconData` passed to `Icon` triggers `non_const_argument_for_const_parameter`;
`// ignore:` it only if you accept losing tree-shaking for that icon.

## `onReorder` → `onReorderItem` (not covered by `dart fix`)

Applies to `ReorderableListView(.builder)`, `ReorderableList`, `SliverReorderableList`.
**`onReorderItem` passes an already-corrected `newIndex`** — delete the old adjustment:

```diff
-onReorder: (oldIndex, newIndex) {
-  if (oldIndex < newIndex) newIndex -= 1;
+onReorderItem: (oldIndex, newIndex) {
   final item = items.removeAt(oldIndex);
   items.insert(newIndex, item);
 },
```

Keeping `newIndex -= 1` inside `onReorderItem` is an off-by-one bug when dragging down. To
reuse a helper that expects the old semantics: `if (oldIndex < newIndex) newIndex += 1;`.

## `cacheExtent` / `cacheExtentStyle` → `scrollCacheExtent`

`ListView`, `GridView`, `CustomScrollView`, `Viewport`, `ReorderableListView`, render objects:

```diff
-ListView(cacheExtent: 500, ...)
+ListView(scrollCacheExtent: const ScrollCacheExtent.pixels(500), ...)

-Viewport(cacheExtent: 0.5, cacheExtentStyle: CacheExtentStyle.viewport, ...)
+Viewport(scrollCacheExtent: const ScrollCacheExtent.viewport(0.5), ...)
```

## Smaller ones

- **`CupertinoPageTransitionsBuilder`** moved to the Cupertino library: with material_ui,
  also `import 'package:cupertino_ui/cupertino_ui.dart'`.
- **`TextInputConnection.setStyle`** deprecated.
- **`RawMenuAnchor`** close order changed —
  https://docs.flutter.dev/release/breaking-changes/raw-menu-anchor-close-order
- **`ListTile`** now reports an error in debug when wrapped in a colored widget —
  https://docs.flutter.dev/release/breaking-changes/list-tile-color-warning
- **Android 17:** large-screen orientation and resizability restrictions are ignored —
  https://docs.flutter.dev/release/breaking-changes/android-large-screens-restrictions-ignored

Read the linked page before changing code for these; this file doesn't carry their details.
