# Android 15 (API 35)

Source (verified 2026-11-07): https://developer.android.com/about/versions/15/behavior-changes-15

## Apps targeting API 35

| Trigger in code | Change | Fix |
|---|---|---|
| Any activity (Views or Compose) | **Edge-to-edge enforced** on Android 15: content draws behind status/navigation bars and cutouts. `setStatusBarColor`, `setNavigationBarColor` (gesture nav), `setNavigationBarDividerColor`, `setDecorFitsSystemWindows` and matching theme attributes (`android:statusBarColor`, ...) are deprecated and have no effect. Non-floating windows get `LAYOUT_IN_DISPLAY_CUTOUT_MODE_ALWAYS`. | Apply insets: Views `ViewCompat.setOnApplyWindowInsetsListener` / `fitsSystemWindows` on `AppBarLayout`, `clipToPadding="false"` on lists; Compose `Scaffold` padding / `WindowInsets.*`; draw a background behind the status bar yourself. `windowOptOutEdgeToEdgeEnforcement` opts out **only while targeting 35** (ignored at 36). Splash crash → `core-splashscreen` ≥ 1.2.0-alpha01. |
| `foregroundServiceType="dataSync"` (and new `mediaProcessing`) | **6 h per 24 h** budget across the app's services of that type; then `Service.onTimeout(int, int)` is called and the service must `stopSelf()` within seconds (else `RemoteServiceException`); new starts throw `ForegroundServiceStartNotAllowedException`. | Implement `onTimeout(startId, fgsType) { stopSelf() }`; prefer WorkManager / user-initiated data transfer jobs for long uploads. Test: `adb shell am compat enable FGS_INTRODUCE_TIME_LIMITS <pkg>`. |
| `BOOT_COMPLETED` receiver starting a foreground service | Can't start FGS of type `dataSync`, `camera`, `mediaPlayback`, `phoneCall`, `mediaProjection`, `microphone` → `ForegroundServiceStartNotAllowedException`. | Schedule WorkManager work from the receiver instead, or defer until the user opens the app. Test: `am compat enable FGS_BOOT_COMPLETED_RESTRICTIONS <pkg>`. |
| `SYSTEM_ALERT_WINDOW` used to start FGS from background | Needs a *visible* `TYPE_APPLICATION_OVERLAY` window too. | Show the overlay first. |
| Kotlin `list.removeFirst()` / `removeLast()` on `MutableList` (after **compileSdk** 35) | Resolves to the new Java 21 `List.removeFirst()` → `NoSuchMethodError` on devices ≤ API 34. | `removeAt(0)` / `removeAt(list.lastIndex)`. |
| `String.format("%0...")`, `Arrays.asList(...).toArray()` cast to `String[]`, locale codes `iw/ji/in` | OpenJDK 17 behavior: stricter format validation, `Object[]` component type, `he/yi/id` codes. | Use `%1$`, `toArray(arrayOf<String>())`, new codes. |
| `NotificationManager.setInterruptionFilter()` / `setNotificationPolicy()` | Can't change global DND; creates an implicit `AutomaticZenRule`. | Use `AutomaticZenRule`. |
| TLS 1.0/1.1 servers | Disallowed. | TLS 1.2+. |
| `PendingIntent` / background activity starts | Creators block BAL by default; can't bring task to front without privileges. | Opt in explicitly with `ActivityOptions` only where needed. |
| `Configuration.screenWidthDp` etc. for layout | Now include system bars. | Use `WindowMetricsCalculator` / insets. |
| `requestAudioFocus()` from background | Fails unless top app or FGS. | Request from foreground/FGS. |
| `elegantTextHeight` | Defaults to `true` (Arabic, Thai, Indic scripts get taller lines). | Test layouts; `false` works only until targeting 36. |
| `TextView` complex scripts / `EditText` min height | More width allocated; locale-based min line height. | `setUseBoundsForWidth`, `useLocalePreferredLineHeightForMinimum=false` if needed. |
