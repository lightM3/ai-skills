# Android 16 (API 36)

Source (verified 2026-11-07): https://developer.android.com/about/versions/16/behavior-changes-16

## Apps targeting API 36

| Trigger in code | Change | Fix |
|---|---|---|
| `android:windowOptOutEdgeToEdgeEnforcement` in themes | **Ignored on Android 16** — edge-to-edge is mandatory (the opt-out still works on Android 15 devices). | Remove the attribute; handle insets (see 35.md). |
| `onBackPressed()` overrides, `KeyEvent.KEYCODE_BACK` handling | **Predictive back on by default**: `onBackPressed` is not called and `KEYCODE_BACK` is not dispatched. | `onBackPressedDispatcher.addCallback(this, object : OnBackPressedCallback(true) { override fun handleOnBackPressed() { ... } })` (enable/disable the callback with state), Compose `BackHandler` / `PredictiveBackHandler`. Temporary opt-out: `android:enableOnBackInvokedCallback="false"` on application/activity. |
| `android:elegantTextHeight` | Deprecated and **ignored**. | Re-test layouts for Arabic, Lao, Myanmar, Tamil, Gujarati, Kannada, Malayalam, Odia, Telugu, Thai. |
| `screenOrientation`, `resizeableActivity="false"`, `min/maxAspectRatio`, `setRequestedOrientation()` | **Ignored on large screens (sw ≥ 600dp)**; app fills the display. Games (`android:appCategory`) exempt. | Adaptive layouts, save state across recreation. Temporary opt-out property `android.window.PROPERTY_COMPAT_ALLOW_RESTRICTED_RESIZABILITY` — **stops working at API 37**. |
| `ScheduledExecutorService.scheduleAtFixedRate` | After the app returns to a valid lifecycle, at most **one** missed execution runs (not all). | Don't rely on catch-up runs. |
| `BODY_SENSORS` / `BODY_SENSORS_BACKGROUND`, heart-rate sensor | Replaced by granular health permissions (`READ_HEART_RATE`, ..., `READ_HEALTH_DATA_IN_BACKGROUND`); mobile apps need a privacy-policy activity or the permission is revoked. | Request the new permissions. |
| Bluetooth bond loss | New `ACTION_KEY_MISSING`, `ACTION_ENCRYPTION_CHANGE`; `CompanionDeviceManager.removeBond(int)`. | Handle the new intents, keep old handling for OEMs that don't send them. |
| `MediaStore.getVersion()` | Unique per app. | Don't parse it. |
| Intents | Safer Intents opt-in: `android:intentMatchingFlags="enforceIntentFilter"`. | Optional hardening. |
| LAN access | Local network permission was opt-in (testing via `am compat enable RESTRICT_LOCAL_NETWORK`); **enforced at 37** — see 37.md. | Prepare now. |
| Photo picker, limited access | App-owned photos are pre-selected. | Nothing required. |
