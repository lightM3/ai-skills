# Android 17 (API 37)

Sources (verified 2026-11-07):
- https://developer.android.com/about/versions/17/behavior-changes-17 (apps targeting 37)
- https://developer.android.com/about/versions/17/behavior-changes-all (all apps on Android 17)
- https://developer.android.com/about/versions/17/release-notes

Stable rollout to Pixel devices started 17 Jun 2026.

## Apps targeting API 37

| Trigger in code | Change | Fix |
|---|---|---|
| `SMS_RECEIVED` receiver / `Telephony.Sms` queries reading OTP codes | Standard SMS containing an OTP is withheld from most apps for **3 hours** (broadcast held back, provider filtered). Exempt: default SMS app, connected-device companion apps. | Use **SMS Retriever API** (app-hash SMS, no permission) or **SMS User Consent API**; drop `RECEIVE_SMS`/`READ_SMS` if only used for OTP. |
| NSD/mDNS discovery, sockets to LAN IPs (printers, cameras, casting, IoT), multicast | New runtime permission **`ACCESS_LOCAL_NETWORK`** (in the `NEARBY_DEVICES` group; no extra prompt if a NEARBY_DEVICES permission is already granted). Opt-in on 16, enforced at 37. | `<uses-permission android:name="android.permission.ACCESS_LOCAL_NETWORK"/>` + request at runtime before discovery/connect, or use a system device picker (no prompt). |
| `android:screenOrientation`, `resizeableActivity="false"`, `minAspectRatio`/`maxAspectRatio`, property `android.window.PROPERTY_COMPAT_ALLOW_RESTRICTED_RESIZABILITY` | On displays with smallest width ≥ 600dp these restrictions are **ignored**. Introduced at API 36 with an opt-out; **the opt-out is not honored at 37**. Games (`android:appCategory="game"`) are exempt. | Remove the opt-out property (dead at 37); make layouts work in any orientation/size (window size classes, save state across resizes). |
| `ContentCaptureManager.setContentCaptureEnabled(false)` | No longer disables content capture. | `window.setFlags(WindowManager.LayoutParams.FLAG_SECURE, WindowManager.LayoutParams.FLAG_SECURE)` on sensitive screens. |
| `ActivityOptions...MODE_BACKGROUND_ACTIVITY_START_ALLOWED` with `IntentSender` / `PendingIntent` | Background Activity Launch restrictions now cover `IntentSender`. | Use **`MODE_BACKGROUND_ACTIVITY_START_ALLOW_IF_VISIBLE`**; check StrictMode/lint. |
| `AppWidgetManager.updateAppWidget` with bitmaps in RemoteViews | Total bitmap memory above the cap now **throws `IllegalArgumentException`** (below 37: only a log warning). Cap ≈ **6 × screen width × height** bytes (bitmaps and bitmap-backed `Icon`s count; URI images don't count against IPC but are decoded at full size by the host). | Compute budget from `WindowManager.currentWindowMetrics.bounds` (API 30+); downsample (`inSampleSize`, decode to slot size), `Bitmap.Config.RGB_565` for opaque images, or use `setImageViewUri`; Glance: decode once in `provideGlance`, override `onCompositionError`; prefer full `updateAppWidget` over `partiallyUpdateAppWidget` when swapping images. |
| Reflection/JNI writing `static final` fields | `Field.set` on static final → `IllegalAccessException`; JNI `SetStatic*Field` crashes. | Remove such code (often in test hacks, old libraries). |
| Reflection on `android.os.MessageQueue` internals | New lock-free MessageQueue; private fields/methods may be gone. | Remove reflection; update libraries that do it. |
| TLS clients (HttpEngine, WebView, OkHttp) | Encrypted Client Hello used when library + server support it. | Opt out per domain with `<domainEncryption>` in network security config if needed. |
| HTTPS cert chains | **Certificate Transparency on by default** (was opt-in on 16). | Make sure server certs are CT-logged (private/enterprise CAs!). |
| `System.load()` of a writable file | Native libs loaded dynamically must be read-only, else `UnsatisfiedLinkError`. | `file.setReadOnly()` before loading; avoid dynamic loading. |
| `ContactsContract.Data` with `ACCOUNT_NAME`/`ACCOUNT_TYPE`/`ACCOUNT_TYPE_AND_DATA_SET` | Columns removed from Data. Queries without `READ_CONTACTS` use strict columns/grammar. | Read account columns from `RawContacts` (join on `RAW_CONTACT_ID`). |
| Background audio (playback, focus, volume) | Restricted from background; at 37 needs a foreground service with while-in-use capability (or exact-alarm permission + `USAGE_ALARM`). | Start audio from a visible activity or proper FGS; check focus result. |
| Custom `InputConnection` / IMEs | New CJKV composition accessibility APIs (`TextAttribute.isTextSuggestionSelected()`, `AccessibilityEvent.setTextChangeTypes()`). | Adopt if you implement an IME/custom editor; `TextView` is automatic. |
| Bluetooth RFCOMM `InputStream.read()` | Returns `-1` on close/disconnect. | Check for `-1` in read loops. |

## All apps on Android 17 (regardless of targetSdk)

- **Memory limits** per app based on device RAM; killed apps show `REASON_OTHER` with
  `ApplicationExitInfo.getDescription()` containing `MemoryLimiter:AnonSwap`. Test with `adb shell am memory-limiter ...`.
- **SMS OTP:** WebOTP-format and SMS-Retriever-hash messages are held 3 h from apps that aren't the
  intended (domain-verified) recipient.
- `android:usesCleartextTraffic` is deprecated (removal in a future release) → use a network security config
  (minSdk < 24: keep the attribute *and* add the config).
- Implicit URI grants for `ACTION_SEND`/`ACTION_SEND_MULTIPLE`/`ACTION_IMAGE_CAPTURE` **end in Android 18** →
  add `FLAG_GRANT_READ_URI_PERMISSION` (+ WRITE for image capture) now; StrictMode `detectImplicitUriPermissionGrant()`.
- Keystore key cap per app: 50,000 keys when targeting 37 (`ERROR_TOO_MANY_KEYS`), 200,000 otherwise.
- Cross-profile loopback traffic blocked.
- IME visibility is not restored after an unhandled config change → `stateAlwaysVisible` or request the IME in `onCreate`.
- Fewer activity restarts: keyboard, navigation, touchscreen, color mode and desk UI-mode changes no
  longer recreate activities by default; opt back in with `android:recreateOnConfigChanges`.
- Background audio from invalid lifecycle states fails silently (focus → `AUDIOFOCUS_REQUEST_FAILED`).
- Touchpad pointer capture sends relative events; `View.requestPointerCapture(View.POINTER_CAPTURE_MODE_ABSOLUTE)` for raw positions.
- Bluetooth: automatic re-pairing on bond loss; `EXTRA_PAIRING_CONTEXT` on `ACTION_PAIRING_REQUEST`.

## New APIs worth suggesting

Contact picker `ACTION_PICK_CONTACTS` (no `READ_CONTACTS`), `USE_LOCATION_BUTTON` (system location button),
`Activity.setHandoffEnabled()` (cross-device handoff), `ProfilingTrigger.TRIGGER_TYPE_ANOMALY`,
photo-picker UI customization, `AlarmManager.setExactAndAllowWhileIdle(..., OnAlarmListener)`.
